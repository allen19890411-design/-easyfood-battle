# EasyFood 美食大作戰

這是一個使用 HTML、CSS、JavaScript 製作的前端網頁小遊戲。

## 遊戲玩法
- 使用方向鍵 ← → 或 A / D 控制外送員移動
- 接住美食可以加分
- 接住星星可以短時間雙倍分數
- 接住時鐘可以增加遊戲時間
- 碰到炸彈會扣生命
- 生命歸零或時間結束，遊戲結束

## 檔案說明
- index.html：網頁主結構
- style.css：網頁樣式與動畫
- script.js：遊戲功能與互動
- README.md：專案說明

## GitHub Pages 部署方式
1. 到 GitHub 建立新的 Repository，例如 easyfood-game
2. 上傳本資料夾內的所有檔案
3. 到 Settings → Pages
4. Source 選 Deploy from a branch
5. Branch 選 main，資料夾選 /root
6. 儲存後等待約 1 分鐘
7. 取得網址：https://你的帳號.github.io/easyfood-game/
